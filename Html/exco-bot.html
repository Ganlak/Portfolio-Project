EXCO Automation Bot — Intelligent IT Operations

A deployed ChatOps automation bot that classifies IT-operations requests and routes them to the right specialist agent. Built as a LangGraph workflow with an Azure OpenAI GPT-4o intent classifier, it distinguishes Root Cause Analysis, Metrics, and General requests across ten IT topics and seven operational categories, then dispatches each to the appropriate downstream agent.

Key Achievements

  • Completed & deployed: A production ChatOps flow (Flow ID 101) running behind a FastAPI backend and LangGraph executor.
  • Multi-dimensional classification: Every request is classified along three dimensions — intent (3), topic (10), and category (7) — for precise routing.
  • Agent routing: The intent classifier routes to an RCA Agent, a Metrics Agent, or a general response path based on the detected intent.
  • Conversation-aware: Uses conversation history so classification accounts for the ongoing dialog, not just the latest message.
  • Config-driven workflow: The flow is defined declaratively in flowbook.yaml and compiled by a WorkflowGenerator — generated files are never edited by hand.

Classification Schema

  • Intent (3): RCA, METRICS, GENERAL.
  • Topic (10): printer, endpoint, network, meeting_room, collaboration, server, application, security, mobile, storage.
  • Category (7): performance, availability, compliance, patching, security, capacity, configuration.

Technical Architecture

The bot sits inside a layered ChatOps stack that takes a user query from a React frontend down to a routed agent response:

  • Frontend: React chat interface.
  • ChatOps Backend: FastAPI service (port 8000) handling requests.
  • LangGraph Executor: FastAPI service (port 8001) that runs compiled workflows.
  • EXCO Bot Workflow: The Flow ID 101 graph that invokes the intent classifier tool.
  • Intent Classifier Agent: Azure OpenAI GPT-4o with dedicated prompts and input/output schemas.
  • Routing: RCA Agent, Metrics Agent, or General Response based on classification.

Workflow Design

  • Declarative flow: Nodes, edges, and config are specified in flowbook.yaml (timeout, retry, and error-handling support built in).
  • Auto-generated code: A WorkflowGenerator compiles agent.py, tools, state, nodes, schemas, and langgraph.json from the flowbook.
  • Consolidated config: Tool-specific environment files are merged into a single consolidated .env at build time.
  • MCP tools: Includes test and discovery scripts for the bot's MCP tool set.

Technology Stack

  • Orchestration: LangGraph
  • LLM: Azure OpenAI GPT-4o
  • Backend: FastAPI (ChatOps + LangGraph executor)
  • Frontend: React
  • Config: flowbook.yaml + consolidated .env
  • Tooling: Model Context Protocol (MCP) tools

Business Impact

  • Automates triage of IT-operations requests directly inside a chat interface
  • Precise three-dimensional classification routes work to the right specialist agent
  • Declarative, generator-driven workflows make new flows fast and consistent to ship
  • Conversation awareness improves accuracy on multi-turn operational requests
