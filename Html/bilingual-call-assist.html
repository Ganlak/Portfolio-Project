ThubIQ — Bilingual Call Assist

A real-time Spanish/English translation assistant for US call centers. The customer speaks Spanish (or Spanglish — mixed Spanish and English) and the human agent reads a live English translation in a dashboard, then replies in English by voice — with the customer hearing natural Spanish back. Built on LiveKit Agents with a streaming STT → translation → TTS pipeline and a live React dashboard.

Key Achievements

  • Live bilingual bridge: Customer Spanish/Spanglish is transcribed and translated to English on screen in real time, while the agent's English replies are spoken back to the customer in Spanish.
  • Zero new infrastructure: Reuses existing Azure OpenAI, Deepgram, ElevenLabs, and LiveKit credentials — no new resources to provision.
  • Streaming dashboard: FastAPI + Server-Sent Events push transcripts and translations to a React/Vite/Tailwind UI as the conversation unfolds.
  • Full call capture: Every call is saved as a JSON transcript and a WAV recording (mic + speaker) for QA and review.
  • Scenario personas: Swappable customer scenarios (e.g., insurance claim, healthcare appointment) for realistic agent training and demos.

Technical Architecture

The system orchestrates a low-latency voice pipeline through LiveKit Agents with each layer handled by a best-in-class component:

  • Speech-to-Text: Deepgram Nova-3 streaming transcription of the customer's Spanish/Spanglish audio.
  • Translation: Azure OpenAI GPT-4o-mini for Spanish → English translation surfaced to the agent.
  • Spanish TTS: ElevenLabs Multilingual v2 voices the agent's English replies back to the customer in Spanish.
  • Customer Persona LLM: Azure OpenAI GPT-4o-mini drives the simulated Spanish-speaking customer for the POC.
  • Orchestration: LiveKit Agents handles real-time audio routing and participant management.
  • Backend: FastAPI with SSE event streaming (dashboard_api.py, live_bus.py).
  • Frontend: React + Vite + Tailwind dashboard with a Spanish/English split view.
  • Recording: WAV capture of both mic and speaker channels (recording.py).

System Flow

  • 1. Warm-up: The backend pre-warms the LiveKit agent; the dashboard status pill turns green and shows "Ready".
  • 2. Start call: The agent (customer persona) begins speaking Spanish immediately.
  • 3. Listen & read: The left column shows the customer's Spanish plus the English translation beneath it; the agent hears Spanish through the speakers.
  • 4. Agent replies: The agent speaks English into the mic; their words appear in the right column and are voiced back in Spanish to the customer.
  • 5. End call: The transcript is saved as JSON and the audio as WAV for later review.

Technology Stack

  • STT: Deepgram Nova-3
  • Translation & Persona LLM: Azure OpenAI GPT-4o-mini
  • Spanish TTS: ElevenLabs Multilingual v2
  • Orchestration: LiveKit Agents
  • Backend: FastAPI + Server-Sent Events
  • Frontend: React + Vite + Tailwind CSS
  • Recording: WAV (mic + speaker capture)

Business Impact

  • Lets English-only agents serve Spanish-speaking customers without bilingual hiring
  • Real-time on-screen translation reduces miscommunication and call handle time
  • Reuses existing AI credentials, so deployment cost and provisioning overhead stay near zero
  • Saved transcripts and recordings support QA, compliance, and agent coaching

Future Enhancements

  • Additional language pairs beyond Spanish/English
  • Live agent assist with suggested responses and sentiment cues
  • CRM integration for automatic call logging and customer lookup
  • Analytics dashboard for translation latency and call outcomes
