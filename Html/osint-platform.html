OSINT Agentic AI Intelligence Platform

An integrated Open Source Intelligence (OSINT) platform for law enforcement, built with a multi-agent AI architecture that connects siloed systems into a unified intelligence layer. Designed for the Ministry of Home Affairs and police departments across India (Maharashtra as pilot state), it uses a LangGraph hub-and-spoke orchestration of seven specialized agents over a full-stack, container-orchestrated backend.

Key Achievements

  • Seven-agent orchestration: A LangGraph hub-and-spoke design coordinates seven specialized agents that collaborate in real time on intelligence tasks.
  • Unified intelligence layer: Connects multiple siloed law-enforcement data sources (criminal records, courts, emergency calls, social media, CCTV metadata) into a single queryable platform.
  • Multi-database backbone: Combines PostgreSQL + PostGIS (geospatial), Neo4j (criminal-network graphs), Redis (cache), and ChromaDB (vector search) behind one async FastAPI service.
  • Full-stack delivery: React 19 + TypeScript frontend with nine main pages (dashboard, chat, map, network graph, etc.) backed by a documented API.
  • Container-orchestrated: Docker Compose for development with a path to Azure Kubernetes Service for production.

The Seven Agents

  • Supervisor: Intent classification and routing across the agent network.
  • Investigation Chatbot: General OSINT queries and investigative guidance.
  • Criminal Profiler: Criminal records lookup and risk scoring.
  • Social Media Threat Monitor: Threat detection and sentiment analysis across platforms.
  • Criminal Network Mapper: Graph analysis and hub detection over Neo4j relationships.
  • Crime Analyst: Hotspot analysis and patrol optimization using geospatial data.
  • MHA Briefing Generator: Executive-level intelligence summaries.

Technical Architecture

  • Backend: FastAPI (Python 3.11) with full async support.
  • AI Orchestration: LangGraph hub-and-spoke with seven specialized agents and tools.
  • LLM: Azure OpenAI GPT-4o.
  • Databases: PostgreSQL + PostGIS, Neo4j (graph), Redis (cache), ChromaDB (vectors).
  • Frontend: React 19 + TypeScript + Vite + TailwindCSS with Zustand state management.
  • Ingestion: A sources → transform → sinks data pipeline feeding the intelligence layer.
  • Middleware: Authentication, logging, and rate limiting.
  • Infrastructure: Docker Compose (dev), Azure Kubernetes Service (prod).

Data Sources (Read-Only)

  • CCTNS: Criminal records and FIRs across a national network of police stations.
  • ICJS: Courts, prisons, and prosecution data.
  • Dial 100: Emergency call records.
  • Social Media: Major platforms integrated via APIs (dummy/sandbox data in the POC).
  • CCTV / Safe City: Camera metadata and feed references.

Key Differentiators

  • An integrated Agentic AI OSINT platform purpose-built for law enforcement
  • Seven autonomous AI agents collaborating in real time
  • Geospatial, graph, relational, and vector intelligence unified in one stack
  • Bilingual (English + Hindi) support on the roadmap

Business Impact

  • Breaks down data silos so investigators query many sources from one interface
  • Network mapping and hotspot analysis support proactive policing and patrol optimization
  • Executive briefing generation turns raw intelligence into decision-ready summaries
  • Container-first design enables secure, scalable deployment from pilot to production
