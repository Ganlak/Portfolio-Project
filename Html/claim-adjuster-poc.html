Claim Adjuster Voice AI — Alex

A production-grade autonomous voice AI agent that conducts recorded-statement interviews for insurance claims. Alex handles first-notice-of-loss intake end to end — asking dynamic follow-up questions, capturing structured claim entities in real time, and flagging fraud, litigation risk, and sentiment shifts during the conversation. Built on LiveKit Agents with a Deepgram → Azure OpenAI → ElevenLabs pipeline and FAISS-grounded claim guidelines.

Key Achievements

  • Fully autonomous interviews: Conducts recorded statements with no human agent required, dynamically adapting follow-up questions based on the claimant's responses.
  • Real-time structured claim file: Extracts and records claim entities live via tool calls (record_entity, record_consent), producing a complete claim JSON by the end of the call.
  • In-call risk signals: Detects and flags fraud indicators, litigation risk, and sentiment changes mid-conversation through dedicated tools.
  • Post-call fraud triage: An LLM pass over the full transcript produces an SIU-style fraud assessment; every MEDIUM-or-above risk is routed to a human-review queue (triage, never a determination).
  • Inbound & outbound: Handles inbound calls via Twilio SIP and can place outbound calls with Answering Machine Detection, graceful voicemail handling, and call context passed to the agent.
  • Full artifact trail: Each call produces a WAV recording, a structured claim JSON, a PDF report, a quality critique, and a fraud assessment.

Technical Architecture

The system routes a claimant phone call through Twilio SIP into LiveKit Cloud, where the Alex agent runs a low-latency voice loop grounded in claim-handling guidelines:

  • Voice Pipeline: LiveKit Agents 1.3 for audio routing, participant management, and telephony bridging.
  • Speech-to-Text: Deepgram Nova-2 streaming transcription with Silero VAD for speech detection.
  • LLM: Azure OpenAI GPT-4o-mini for reasoning, question generation, and entity extraction.
  • Knowledge Base: FAISS vector index over claim guidelines with Azure OpenAI embeddings (text-embedding-ada-002) for grounded responses via a search_guidelines tool.
  • Text-to-Speech: ElevenLabs for natural voice synthesis.
  • Turn Detection: LiveKit Multilingual model to know when the claimant has finished speaking.
  • Telephony: Twilio SIP trunk with dispatch rules into LiveKit Cloud.
  • Tools: record_entity, record_consent, flag_fraud, flag_sentiment, flag_litigation, search_guidelines.

Call Flow

  • 1. Connect: Claimant call (inbound or AMD-screened outbound) is routed via Twilio SIP to a LiveKit room where Alex joins.
  • 2. Consent & intake: Alex captures recording consent, then conducts the statement, asking dynamic follow-ups.
  • 3. Live extraction: Entities, fraud/litigation/sentiment flags are recorded in real time via tool calls.
  • 4. On hangup: A claim JSON and WAV are saved, then a PDF report, quality critique, and fraud triage are generated.
  • 5. Routing: MEDIUM+ fraud-risk calls are flagged for human (SIU) review.

Quality & Analytics

  • Per-call critique: Each call is graded and stored as a critique JSON for QA.
  • Aggregate analytics: A deterministic, no-LLM module aggregates metrics across all calls and critiques for a dashboard view.
  • Prompt versioning: Versioned prompts with active/promote workflow for safe iteration on the agent's behavior.
  • Dashboard & reports: HTML dashboard and per-call reports for review.

Technology Stack

  • Voice Framework: LiveKit Agents 1.3
  • STT: Deepgram Nova-2
  • LLM: Azure OpenAI GPT-4o-mini
  • TTS: ElevenLabs
  • VAD: Silero
  • Turn Detection: LiveKit Multilingual Model
  • Vector Database: FAISS
  • Embeddings: Azure OpenAI text-embedding-ada-002
  • Telephony: Twilio SIP Trunk (inbound + outbound with AMD)
  • Orchestration: LangChain LCEL (fraud analysis & critique chains)

Responsible AI Framing

  • Fraud analysis is a triage tool, not a fraud determination engine
  • Every assessment at MEDIUM risk or above carries a human-review-required flag
  • The indicator taxonomy mirrors industry-standard signals used by real SIU teams
  • Recording consent is captured explicitly at the start of each statement

Business Impact

  • Replaces or augments the human first-notice-of-loss adjuster for routine intake
  • Produces a complete, structured claim file automatically at the end of each call
  • Surfaces fraud and litigation risk early, routing high-risk calls to human investigators
  • 24/7 inbound and outbound capability with full audit artifacts per call
